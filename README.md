# Boston Cleaning Services

Marketing site for Boston Cleaning Services (bostoncleaningservices.com).
Next.js 16 App Router, Tailwind CSS 4, deployed on Netlify with Netlify Forms.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Structure

- `src/app` routes (home, services, service areas, checklist, about, contact, legal)
- `src/lib/data` all page content and business data
- `src/lib/constants.ts` phone, email, nav, and site URL
- `src/lib/schema.tsx` JSON-LD generators
